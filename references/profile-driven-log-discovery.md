# 项目日志发现清单

在写任何正式 profile 前，项目适配 Skill 必须对真实日志逐项取证并保存到自己的工作区。每项写明来源、端口/角色、原文片段、游标、是否镜像、应提交的 event type、唯一展示捕获、关联键、阶段、空值策略和正反例。

| 要点 | 需采集的情况 | profile 必填内容 |
| --- | --- | --- |
| 初始化 | 启动完成、稳定、失败 | 初始化事实、来源、稳定窗口 |
| 命令 | 发送、直接回执、串口回执、旁证、超时、重试 | 白名单、回执/旁证规则、超时和重试 |
| 重启 | 正常重启、连续重启、恢复失败 | 重启事实、epoch 和恢复策略 |
| 识别/云端 | 正常、空结果、重复、错配、迟到 | 各阶段事实、关联、空值、镜像 |
| 播放器 | 准备、活动、结束、错误、未知 | 原始展示捕获、state_class、窗口和降噪策略 |
| 多来源 | 单端口、双端口镜像、乱序 | source/port/role 范围、镜像 identity 和窗口 |
| 安全 | 会造成设备/数据/人员风险的事实 | safety_eligible、原因、风险类型和正反 fixture |

调试阶段先使用原始记录回放验证规则，确认每个 capture 与串口原文一致，再把同一规则冻结到 formal profile。工具日志不显示正则文本。
