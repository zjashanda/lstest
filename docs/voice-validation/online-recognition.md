# 在线识别验证 Wiki

资料来源：`oldTime/legacy_20260526_144646/satellite/voice-test-plan-designer`。旧目录只作为归档来源，当前方案设计和用例生成应优先读取本 Wiki 与当前 Cucumber/Runtime registry。


## Polaris 落地要点

- 当前 L0/L1 能力包括半双工、全双工、在线 one-shot、在线 VAD smoke、在线混合交互压测和媒体响应链路分析。
- API 场景必须先确认设备端已切到 UAT/SIT/PRO 对应环境，再调用接口；只改 API 环境不代表设备生效。
- 在线响应不能只看“云端返回成功”，还要看设备日志中的 TTS/media/player start/stop/complete 和 HTTP/media error。
- 半双工/全双工必须分开统计，播报中是否允许识别、是否允许打断要按需求定义判断。

## 原始方法沉淀

## 在线识别

### 半双工识别
- 执行规则：每条在线语料前先唤醒设备，再说或播放在线语料，记录 ASR 文本、识别为空、超时和设备反馈。
- 执行规则：在线识别主关注 ASR 文本与预期词条文本是否一致；技能、应答语和设备执行结果作为附带记录，除非项目明确要求。
- 关注结果：ASR 文本正确、文本错误、识别为空、超时、网络或云端异常。
- 统计公式：在线 ASR 句准 = ASR 文本正确次数 / 有效在线语料总次数 * 100%；识别为空率 = 识别为空次数 / 有效在线语料总次数 * 100%。
- 统计结果：在线 ASR 句准、识别为空率、文本错误样本、超时样本。

### 全双工识别
- 执行规则：设备开启全双工后，首次唤醒成功，后续在未退出识别状态时连续说在线语料。
- 执行规则：记录全双工状态、语料顺序、ASR 文本和识别稳定性。
- 关注结果：全双工状态下 ASR 句准、识别为空、状态异常或连续失败。
- 统计公式：全双工 ASR 句准 = 全双工 ASR 文本正确次数 / 有效全双工在线语料总次数 * 100%。
- 统计结果：全双工 ASR 句准、识别为空率、串扰率、异常样本。

### 方言/口音在线识别
- 执行规则：使用方言或带口音普通话在线语料单独测试，记录方言/口音标签和 ASR 文本。
- 执行规则：普通话和方言/口音结果分开统计，避免总体句准掩盖方言问题。
- 关注结果：方言/口音 ASR 文本是否正确，是否识别为空或文本错误集中。
- 统计公式：方言/口音 ASR 句准 = 方言/口音 ASR 文本正确次数 / 有效方言/口音在线语料总次数 * 100%。
- 统计结果：方言/口音 ASR 句准、识别为空率、badcase。

### 在线噪声误识别
- 执行规则：唤醒后不播放在线目标语料，只播放不含目标指令的噪声素材，记录 ASR 文本和是否触发可执行控制指令。
- 执行规则：噪声素材与在线正集语料分开统计，触发后可保留 SID 作为复核证据。
- 关注结果：噪声是否识别成可执行控制指令，是否触发高风险动作。
- 统计公式：在线噪声误识别率 = 噪声被识别成可执行指令次数 / 有效在线噪声测试次数 * 100%。
- 统计结果：在线噪声误识别率、触发指令清单、SID/日志证据。

### 全双工识别打断场景
- 执行规则：设备自播未结束前说在线语料，检查是否能完成在线识别。
- 执行规则：记录自播内容、自播音量、人声分贝、打断时机、ASR 文本和设备反馈。
- 关注结果：回声、自播、打断场景下 ASR 是否正确，是否识别为空或超时。
- 统计公式：打断识别成功率 = 打断场景 ASR 正确次数 / 有效打断在线语料总次数 * 100%。
- 统计结果：打断识别成功率、ASR 句准、识别为空率、异常样本。

### 在线 oneshot
- 执行规则：使用唤醒词和在线语料连说或短间隔音频，记录唤醒和在线 ASR 两个环节。
- 执行规则：失败原因需拆分为唤醒失败、在线 ASR 未识别、在线 ASR 文本错误、云端或网络异常。
- 关注结果：整体链路是否成功，失败主要发生在哪个环节。
- 统计公式：在线 oneshot 整体成功率 = 唤醒成功且在线 ASR 正确次数 / 有效在线 oneshot 总次数 * 100%。
- 统计结果：在线 oneshot 整体成功率、分环节失败统计、异常样本清单。

### VAD 专项
- 执行规则：使用短句、长句、尾弱音、带停顿语料测试端点表现，记录 ASR 文本和截断/超时情况。
- 执行规则：VAD 问题需保留录音、ASR 文本和日志证据，便于判断首尾字截断或误切。
- 关注结果：首尾字截断、识别为空、超时、漏字、多字。
- 统计公式：VAD 专项 ASR 句准 = VAD 专项文本正确次数 / 有效 VAD 专项样本数 * 100%；截断率 = 截断样本数 / 有效 VAD 专项样本数 * 100%。
- 统计结果：VAD 专项 ASR 句准、截断率、超时样本、badcase。

### 弱网稳定性
- 执行规则：在弱网环境下使用在线语料压测，记录网络条件、ASR 文本、超时、失败和设备状态。
- 执行规则：网络异常和算法/设备异常要分开记录；证据不足时不直接归因。
- 关注结果：弱网下识别稳定性、超时、设备重启、进程异常或日志中断。
- 统计公式：弱网成功率 = 弱网下在线识别成功次数 / 有效弱网样本数 * 100%；超时率 = 弱网超时次数 / 有效弱网样本数 * 100%。
- 统计结果：弱网成功率、超时率、稳定性异常记录。

### 云端服务稳定性
- 执行规则：正常网络下使用同一批在线语料在不同时段重复测试，记录 ASR 句准和服务异常。
- 执行规则：同一语料多时段结果需保持可比，网络条件和设备版本应记录清楚。
- 关注结果：ASR 句准是否因云端服务波动明显变化，是否出现集中超时或错误。
- 统计公式：多时段句准波动 = 最高时段 ASR 句准 - 最低时段 ASR 句准。
- 统计结果：多时段 ASR 句准、句准波动、服务异常记录。

### 在线响应时间
- 执行规则：记录在线语料人声结束到 TTS 回复、提示音或设备动作开始的端到端时间。
- 执行规则：只统计成功样本；失败、超时、网络异常样本单独记录，不混入平均值。
- 关注结果：端到端耗时、最大值、最小值、明显慢样本和网络波动影响。
- 统计公式：平均在线响应时间 = 成功样本在线响应时间总和 / 成功样本数。
- 统计结果：在线响应时间平均值、最大值、最小值、超阈值样本。

说明：SID 复核不是测试项；如需要，可在方案执行说明中作为 badcase 复核手段提及，不纳入测试范围。
