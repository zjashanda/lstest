# 误唤醒验证 Wiki

## Polaris 落地要点

- 当前 L0/L1 能力包括静默监听、人声干扰 smoke、白噪声 smoke 和长期在线压测中的额外 wake 记录。
- 串口 logger 无日志、设备重启、声卡播放失败、噪声素材缺失都应先 BLOCKED，不可误判成算法误唤醒。
- 误唤醒用“次数/时长”或“触发率”统计，不能和正式唤醒率混算。

## 误唤醒

### 安静误唤醒
- 执行规则：设备在安静或低底噪环境中长时间运行，不主动说唤醒词，持续采集触发事件、录音和日志。
- 执行规则：误唤醒按场景时长或场景总次数判断，不按播放语料条数统计。
- 关注结果：是否发生误唤醒、触发唤醒词、触发时间、设备状态异常。
- 统计公式：安静误唤醒频度 = 安静场景误唤醒次数 / 安静场景测试时长。
- 统计结果：安静误唤醒次数、单位时长频度、触发事件清单。

### 人声噪误唤醒
- 执行规则：播放电视、新闻、综艺、闲聊、音乐等人声噪素材并长时间运行，持续采集触发事件、录音和日志。
- 执行规则：触发后应进行听音复核，区分素材含唤醒词、疑似近音、非近音声音和设备异常。
- 关注结果：人声噪是否触发唤醒，触发是否集中在某类素材或某个唤醒词。
- 统计公式：人声噪误唤醒频度 = 人声噪误唤醒次数 / 人声噪测试时长。
- 统计结果：人声噪误唤醒次数、单位时长频度、触发分类、触发唤醒词。

### 非人声噪误唤醒
- 执行规则：播放风声、水流、炒菜、油烟机、开关门、鼾声等非人声噪素材并长时间运行。
- 执行规则：记录素材类型、测试时长、触发事件、录音和日志。
- 关注结果：非人声噪是否触发唤醒，触发是否集中在某类非人声素材。
- 统计公式：非人声噪误唤醒频度 = 非人声噪误唤醒次数 / 非人声噪测试时长。
- 统计结果：非人声噪误唤醒次数、单位时长频度、触发分类、触发唤醒词。

### 多点噪误唤醒
- 执行规则：多方向、多内容噪声叠加播放并长时间运行，记录噪声来源、方向组合、测试时长和触发事件。
- 执行规则：多点噪属于复杂噪声专项，应与单点人声噪、非人声噪结果分开统计。
- 关注结果：复杂噪声场景是否触发唤醒，触发是否集中在某些噪声组合。
- 统计公式：多点噪误唤醒频度 = 多点噪误唤醒次数 / 多点噪测试时长。
- 统计结果：多点噪误唤醒次数、单位时长频度、触发场景清单。

### 高/低灵敏度误唤醒
- 执行规则：在不同唤醒灵敏度配置下执行误唤醒测试，记录灵敏度档位、测试时长和触发事件。
- 执行规则：不同灵敏度结果分开统计，不直接合并成一个误唤醒次数。
- 关注结果：灵敏度变化是否影响误唤醒风险，是否出现高灵敏度明显恶化。
- 统计公式：分灵敏度误唤醒频度 = 该灵敏度误唤醒次数 / 该灵敏度测试时长。
- 统计结果：分灵敏度误唤醒次数、单位时长频度、触发样本。

### 整机长期挂机
- 执行规则：真实设备长时间运行，持续采集触发事件、设备状态、录音和日志。
- 执行规则：长期挂机同时关注误唤醒和稳定性异常，触发事件需能追溯到时间点、日志和录音。
- 关注结果：长期运行中的偶发误唤醒、设备重启、日志停止、进程异常或状态异常。
- 统计公式：长期挂机误唤醒频度 = 长期挂机误唤醒次数 / 长期挂机测试时长；设备异常频度 = 设备异常次数 / 长期挂机测试时长。
- 统计结果：总测试时长、触发次数、单位时长频度、设备异常记录。

说明：听音确认不是测试项；它是触发事件后的复核方式，用于区分素材含唤醒词、疑似唤醒近音、非近音声音和设备异常。
