# 语音验证测试项索引

资料来源：`oldTime/legacy_20260526_144646/satellite/voice-test-plan-designer`。旧目录只作为归档来源，当前方案设计和用例生成应优先读取本 Wiki 与当前 Cucumber/Runtime registry。

## 等级说明

| 等级 | 含义 |
| --- | --- |
| L0 | 已有 Cucumber/tag/task/runtime，可直接进入执行或压测。 |
| L1 | 当前工具可沉淀并执行 smoke/探索，正式结论需要轮次、阈值或 oracle。 |
| L2 | 可设计方案和用例，但需要正式语料、词表、配置入口或云控权限。 |
| L3 | 需要物理 rig、多设备、噪声场、人工人群或特殊硬件，当前只能沉淀方法。 |
