# 唤醒验证 Wiki

资料来源：`oldTime/legacy_20260526_144646/satellite/voice-test-plan-designer`。旧目录只作为归档来源，当前方案设计和用例生成应优先读取本 Wiki 与当前 Cucumber/Runtime registry。


## Polaris 落地要点

- 当前 L0/L1 能力包括首次唤醒、识别模式唤醒、连续唤醒、随机间隔唤醒、唤醒响应时间小样本、打断唤醒前置/注入。
- 断言必须区分播放成功、设备是否处于待唤醒/识别态、AP/CP/ASR 或 upper 日志是否有 wake marker。
- 临界超时场景不能只看播放进程启动时间；优先使用有效音频起点和 `AudioCompleted - audio_duration_ms` 估算，无法确认时输出 `TIMING_AMBIGUOUS`。
- 额外出现的 wake marker 必须记录为误唤醒候选，不能因为主用例 PASS 就丢弃。

## 原始方法沉淀

## 唤醒

### 首次唤醒
- 执行规则：每次播放唤醒词前，确认设备处于待唤醒状态；优先通过日志确认设备已退出识别模式；如只能靠间隔控制，播放间隔应大于设备识别超时时间。
- 执行规则：按测试场景播放唤醒词音频，抓取唤醒日志和录音，记录唤醒成功、未唤醒、异常唤醒词和连续失败情况。
- 关注结果：唤醒成功、未唤醒、连续未唤醒、唤醒词串扰、日志缺失或设备状态异常。
- 统计公式：首次唤醒率 = 首次唤醒成功次数 / 首次唤醒有效总次数 * 100%；未唤醒率 = 未唤醒次数 / 首次唤醒有效总次数 * 100%。
- 统计结果：首次唤醒率、未唤醒率、连续未唤醒次数、异常样本清单。

### 识别模式唤醒
- 执行规则：第一条先唤醒设备；后续在设备未退出识别模式时继续播放唤醒词；有效间隔通常满足 `1 秒 < 间隔 < 设备识别超时时间`。
- 执行规则：不要求设备退出识别模式，重点确认识别模式下再次说唤醒词是否仍能触发唤醒。
- 关注结果：识别模式下是否成功唤醒、是否被上一轮响应影响、是否连续未唤醒。
- 统计公式：识别模式唤醒率 = 识别模式唤醒成功次数 / 识别模式唤醒有效总次数 * 100%。
- 统计结果：识别模式唤醒率、连续未唤醒次数、异常样本清单。

### 唤醒相似词
- 执行规则：使用项目提供或用户确认的唤醒相似词，逐条播放或喊测，抓取唤醒日志。
- 执行规则：相似词只验证是否被当作正式唤醒词触发，不并入误唤醒场景总次数，也不统计为正式唤醒词串扰率。
- 关注结果：是否触发正式唤醒、触发到哪个唤醒词、是否存在高触发相似词。
- 统计公式：相似词触发率 = 相似词触发正式唤醒次数 / 有效相似词总次数 * 100%。
- 统计结果：相似词触发率、触发唤醒词分布、异常样本清单。

### 唤醒反集
- 执行规则：使用项目提供或用户确认的唤醒反集，先检查样本合法性，再逐条播放或喊测，抓取唤醒日志。
- 执行规则：反集不能是正式唤醒词，也不能与正式唤醒词发音完全相同；音频发成正式唤醒词、缺字、多字或发音含糊时应标为无效样本。
- 关注结果：是否触发正式唤醒、触发到哪个唤醒词、是否存在高触发反集。
- 统计公式：唤醒反集触发率 = 唤醒反集触发正式唤醒次数 / 有效唤醒反集总次数 * 100%。
- 统计结果：唤醒反集触发率、触发唤醒词分布、无效反集样本清单、异常样本清单。

### 打断唤醒
- 执行规则：让设备播放命令词应答语、TTS、音乐或其他自播内容；在播音过程中说唤醒词，记录自播内容类型、自播音量、人声分贝、打断时机和唤醒结果。
- 执行规则：仅适用于支持打断或全双工能力的设备；不支持时标记为不适用，不写成通过。
- 关注结果：自播过程中是否可被唤醒词打断，失败是否集中在特定自播内容、音量或打断时机。
- 统计公式：打断唤醒成功率 = 打断唤醒成功次数 / 有效打断唤醒总次数 * 100%。
- 统计结果：打断唤醒成功率、失败样本、自播类型维度结果。

### 响应时间
- 执行规则：准备至少 20 条唤醒样本，测试过程中同步录音并抓取日志；记录唤醒词最后一个音节结束到唤醒提示音或应答语开始的时间间隔。
- 执行规则：仅统计唤醒成功样本的响应时间；未唤醒样本单独记录失败原因，不混入耗时平均值。
- 关注结果：平均值、最大值、最小值、明显慢样本和超阈值样本。
- 统计公式：平均响应时间 = 成功样本响应时间总和 / 成功样本数；最大/最小响应时间分别取成功样本响应时间极值。
- 统计结果：唤醒响应时间平均值、最大值、最小值、超阈值样本清单。

### 连续唤醒
- 执行规则：连续播放或喊测唤醒词，每次播放之间不设置间隔，抓取全程日志和录音。
- 执行规则：该项属于稳定性专项，主要观察算法是否崩溃、卡死、重启、日志停止输出或出现连续失败，不与正式首次唤醒率混算。
- 关注结果：设备稳定性异常、连续未唤醒、日志中断、进程重启或卡死。
- 统计公式：连续失败次数按连续未唤醒段统计；如需统计专项唤醒率，专项唤醒率 = 连续唤醒成功次数 / 连续唤醒有效总次数 * 100%。
- 统计结果：稳定性异常记录、连续失败次数、专项唤醒率。

### 冷唤醒测试
- 执行规则：设备长时间无语音交互或重启后，播放第一条唤醒词并记录第一次唤醒结果；必要时多轮重复。
- 执行规则：冷唤醒关注冷态第一次唤醒是否成功和是否出现异常日志，不与低功耗唤醒强制等同。
- 关注结果：第一次唤醒成功/失败、恢复识别状态、异常日志、设备重启或卡死。
- 统计公式：冷唤醒成功率 = 冷态第一次唤醒成功次数 / 冷唤醒有效轮次 * 100%。
- 统计结果：冷唤醒成功率、第一次唤醒失败样本、异常日志清单。

### 高低音量交替唤醒
- 执行规则：按“大、小、大、小……”固定交替方式播放唤醒词；大/小音量指到 mic 处的人声分贝，小音量也必须在有效测试音量范围内。
- 执行规则：该项属于稳定性专项，结果作为专项唤醒结果呈现，不与正式首次唤醒率混算。
- 关注结果：大小音量切换后是否稳定唤醒，是否出现连续 3 次以上未唤醒或状态异常。
- 统计公式：高低音量交替唤醒率 = 高低音量交替唤醒成功次数 / 有效交替唤醒总次数 * 100%。
- 统计结果：专项唤醒率、分音量唤醒结果、连续未唤醒次数、异常样本清单。

### 随机间隔唤醒
- 执行规则：上一条唤醒音频结束到下一条开始的间隔随机，间隔通常在 [1,60] 秒之间；抓取全程日志和录音。
- 执行规则：该项不要求每次唤醒都处在同一种设备状态，重点观察随机间隔下状态是否稳定。
- 关注结果：随机间隔下唤醒是否稳定、是否出现状态异常或连续未唤醒。
- 统计公式：随机间隔唤醒率 = 随机间隔唤醒成功次数 / 有效随机间隔唤醒总次数 * 100%。
- 统计结果：专项唤醒率、连续未唤醒次数、状态异常记录。

### 多唤醒词唤醒
- 执行规则：支持多个唤醒词的产品，分别播放每个唤醒词音频；每个唤醒词都要单独统计，不只给整体结果。
- 执行规则：记录目标唤醒词、实际触发唤醒词、未唤醒和串扰方向。
- 关注结果：各唤醒词是否都能唤醒，是否存在某个唤醒词低或串到其他唤醒词。
- 统计公式：分唤醒词唤醒率 = 该唤醒词成功唤醒次数 / 该唤醒词有效总次数 * 100%；唤醒词串扰率 = 唤醒到非目标唤醒词次数 / 有效总次数 * 100%。
- 统计结果：分唤醒词唤醒率、唤醒词串扰率、串扰方向矩阵。

### 多唤醒词切换
- 执行规则：在多个唤醒词之间交替播放或喊测，记录目标唤醒词顺序、实际触发唤醒词和设备状态。
- 执行规则：支持多唤醒词的产品应关注切换过程中是否有状态残留或词间互相影响。
- 关注结果：切换过程中是否稳定唤醒，串扰方向是否集中，是否出现连续失败。
- 统计公式：切换过程唤醒率 = 切换过程成功唤醒次数 / 有效切换唤醒总次数 * 100%；切换串扰率 = 切换过程串扰次数 / 有效切换唤醒总次数 * 100%。
- 统计结果：切换过程唤醒率、串扰方向、连续失败次数。

### DOA 唤醒
- 执行规则：在不同角度播放唤醒词，成功唤醒后检查设备输出的 DOA 角度。
- 执行规则：仅适用于支持 DOA 的产品；不支持时标记为不适用。
- 关注结果：是否输出 DOA，输出角度是否落在允许偏差内，是否存在特定角度异常。
- 统计公式：DOA 准确率 = DOA 正确次数 / 有效 DOA 样本数 * 100%；角度偏差 = 实际输出角度 - 目标角度。
- 统计结果：DOA 准确率、角度偏差分布、无角度输出样本。

### 分布式/唯一唤醒
- 执行规则：多台同组设备同时接收唤醒词，检查是否只有能量最高或预期主设备应答。
- 执行规则：记录设备编号、摆位、能量关系、应答设备和多设备同时应答情况。
- 关注结果：是否多台同时应答，主设备选择是否正确，分布式决策是否稳定。
- 统计公式：唯一应答率 = 仅预期设备应答次数 / 有效分布式唤醒总次数 * 100%；分布式准确率 = 主设备选择正确次数 / 有效分布式唤醒总次数 * 100%。
- 统计结果：唯一应答率、分布式准确率、多设备同时应答案例。

### 低功耗唤醒
- 执行规则：设备进入低功耗后播放唤醒词，检查是否唤醒并恢复常规识别能力。
- 执行规则：仅适用于支持低功耗语音能力的设备；不支持时标记为不适用。
- 关注结果：低功耗状态是否仍可唤醒，唤醒后识别能力是否恢复，恢复耗时是否异常。
- 统计公式：低功耗唤醒率 = 低功耗唤醒成功次数 / 有效低功耗唤醒总次数 * 100%；恢复成功率 = 唤醒后恢复识别成功次数 / 低功耗唤醒成功次数 * 100%。
- 统计结果：低功耗唤醒率、恢复成功率、恢复失败样本、恢复耗时。

### 变换位置唤醒
- 执行规则：用户在不同距离、角度、位置或移动状态下说唤醒词，记录位置变化和唤醒结果。
- 执行规则：该项属于主观体验或专项分析，不直接替代正式客观唤醒率。
- 关注结果：真实交互中是否存在位置相关唤醒问题，问题是否集中在某些方位或移动状态。
- 统计公式：主观位置唤醒成功率 = 位置变化下成功唤醒次数 / 有效位置变化喊测次数 * 100%。
- 统计结果：主观唤醒结果、位置/距离/姿态问题记录、典型 badcase。

### 不同人群唤醒
- 执行规则：覆盖不同性别、年龄、口音、语速的人群或标注音频，按人群维度组织或分析测试结果。
- 执行规则：样本不足时只做风险提示，不直接判断某类人群能力差。
- 关注结果：问题是否集中在特定性别、年龄、口音、语速或方言维度。
- 统计公式：分人群唤醒率 = 该人群唤醒成功次数 / 该人群有效唤醒总次数 * 100%。
- 统计结果：分人群/语速/口音唤醒率、badcase、样本量风险提示。
