# 自由说验证 Wiki

资料来源：`oldTime/legacy_20260526_144646/satellite/voice-test-plan-designer`。旧目录只作为归档来源，当前方案设计和用例生成应优先读取本 Wiki 与当前 Cucumber/Runtime registry。


## Polaris 落地要点

- 当前以需求抽取和小样本 smoke 为主；正式结论依赖权威意图、slot、说法清单和 oracle。
- 自由说用例要保留“目标意图、slot、说法类型、高频/长尾标签”，不能只统计一个总识别率。
- 缺少正式期望时不直接判固件 FAIL，应输出 `REQUIREMENT_REVIEW` 或 `NEEDS_REVIEW`。

## 自由说

### 全意图覆盖
- 执行规则：核对自由说测试数据是否覆盖产品支持的全部自由说意图、关键 slot 和核心说法类型。
- 执行规则：覆盖检查不替代识别率测试；缺失意图或样本不足意图单独列出。
- 关注结果：是否存在缺失意图、缺失 slot、样本不足意图或标注缺失。
- 统计公式：自由说意图覆盖率 = 已覆盖意图数 / 应覆盖意图总数 * 100%。
- 统计结果：自由说意图覆盖率、覆盖清单、缺失项和样本不足项。

### 高频说法识别率
- 执行规则：使用高频词表、核心词清单或核心说法清单中的说法测试，按目标意图比对结果。
- 执行规则：高频说法与非高频说法分开统计，不能混成一个自由说总识别率直接下结论。
- 关注结果：高频说法是否稳定命中目标意图，是否识别为空或串扰。
- 统计公式：高频说法识别率 = 高频说法识别正确次数 / 有效高频说法总次数 * 100%；高频说法串扰率 = 高频说法串扰次数 / 有效高频说法总次数 * 100%。
- 统计结果：高频说法识别率、串扰率、识别为空次数、badcase。

### 非高频说法识别率
- 执行规则：使用非高频或长尾自由说说法测试，按目标意图比对结果。
- 执行规则：长尾表达应保留说法类型和目标意图，便于定位集中失败意图。
- 关注结果：扩展表达是否可用，是否存在集中失败意图或识别为空。
- 统计公式：非高频说法识别率 = 非高频说法识别正确次数 / 有效非高频说法总次数 * 100%。
- 统计结果：非高频说法识别率、串扰率、识别为空次数、badcase。

### 纯 slot 说法
- 执行规则：从句式组合表中提取 slot 文本，按 slot 顺序组合后测试，按目标意图判定。
- 执行规则：纯 slot 说法仍按目标意图统计，不单独把 slot 值当成独立结论。
- 关注结果：纯 slot 说法是否命中目标意图，是否识别为空或串扰。
- 统计公式：纯 slot 说法识别率 = 纯 slot 说法识别正确次数 / 有效纯 slot 说法总次数 * 100%。
- 统计结果：纯 slot 说法识别率、串扰率、识别为空次数、badcase。

### 全量覆盖率测试
- 执行规则：使用全量自由说表、文本合成音频或离线测试集进行覆盖率测试。
- 执行规则：按意图、说法类型和样本来源分组，避免全量结果掩盖低识别率意图。
- 关注结果：全量说法识别高低，低识别率意图或说法。
- 统计公式：自由说覆盖识别率 = 全量说法识别正确次数 / 有效全量说法总次数 * 100%。
- 统计结果：自由说覆盖识别率、低识别率意图、异常样本清单。

### 前缀/后缀/插入语
- 执行规则：基于句式组合表抽取前缀、后缀、插入语组合进行测试。
- 执行规则：记录口语成分类型和目标意图，按类型分组统计。
- 关注结果：口语成分是否导致拒识、串扰或意图错误。
- 统计公式：口语成分识别率 = 带口语成分说法识别正确次数 / 有效带口语成分说法总次数 * 100%。
- 统计结果：识别率、识别为空、串扰率、典型 badcase。

### 口语化命令表达
- 执行规则：体验者知道标准命令后，改成更自然的口语表达进行体验或专项测试。
- 执行规则：口语化表达需记录原标准命令、实际说法和目标意图。
- 关注结果：已知命令的口语化泛化是否可用，未命中表达有哪些。
- 统计公式：口语化表达支持率 = 口语化表达识别正确次数 / 有效口语化表达总次数 * 100%。
- 统计结果：支持/不支持说法、口语化表达支持率、典型未命中表达。

### 自由说反集
- 执行规则：使用用户确认的自由说反集词表测试，记录是否命中正式自由说意图或触发动作。
- 执行规则：自由说反集与高频/非高频正集分开统计，不混入正集识别率。
- 关注结果：反集是否命中预期反集意图，是否串到正式自由说意图或触发动作。
- 统计公式：自由说反集误识别率 = 被识别成正式自由说意图的反集次数 / 有效自由说反集总次数 * 100%。
- 统计结果：自由说反集误识别率、反集串扰率、异常反集词清单。

### 口音/语速/人群
- 执行规则：按口音、语速、人群维度组织或分析自由说测试结果。
- 执行规则：样本不足时只做风险提示，不直接判断某类人群能力差。
- 关注结果：问题是否集中在特定发音维度、年龄或方言。
- 统计公式：分维度自由说识别率 = 该维度识别正确次数 / 该维度有效样本数 * 100%。
- 统计结果：分人群/语速/口音识别结果、badcase、样本量风险提示。

### 主观自由发挥
- 执行规则：只告知功能范围，不给完整说法模板，让体验者按真实习惯表达。
- 执行规则：记录体验者实际说法、目标功能、识别结果和是否可接受。
- 关注结果：真实用户表达是否被支持，未命中表达有哪些。
- 统计公式：主观表达支持率 = 主观表达被正确支持次数 / 有效主观表达总次数 * 100%。
- 统计结果：真实表达支持情况、未命中说法、典型 badcase。

### 响应时间
- 执行规则：记录自由说人声结束到设备反馈、TTS 或动作开始的时间。
- 执行规则：只统计识别成功且链路有效的样本；失败样本单独记录原因。
- 关注结果：平均值、最大值、最小值、明显慢样本。
- 统计公式：平均响应时间 = 成功样本响应时间总和 / 成功样本数。
- 统计结果：自由说响应时间平均值、最大值、最小值、超阈值样本清单。
