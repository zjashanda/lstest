# 命令词验证 Wiki

资料来源：`oldTime/legacy_20260526_144646/satellite/voice-test-plan-designer`。旧目录只作为归档来源，当前方案设计和用例生成应优先读取本 Wiki 与当前 Cucumber/Runtime registry。


## Polaris 落地要点

- 当前 L0/L1 能力包括基础命令词识别、需求命令词小样本、离线 one-shot、识别打断和响应链路 smoke。
- 命令词分母只统计“已成功唤醒后的有效命令样本”；未唤醒要先归前置，不混入命令识别率。
- 断言既看 ASR/keyword/command marker，也要看期望动作或 TTS/media 响应；没有动作 oracle 时只能标记 `NEEDS_REVIEW` 或 exploratory。
- 未播放目标命令却出现命令识别，必须记录为误识别候选。
- 设备控制类命令必须读取 `control-command-actuator-beep-assertion.md`：识别、控制回复、TTS/播报、执行/蜂鸣器反馈要分段断言；蜂鸣器是否应响取决于命令和当前状态，不能简单强制必响。

## 原始方法沉淀

## 命令词

### 基础命令词识别率
- 执行规则：确保设备已进入识别状态后播放命令词音频，按目标意图比对识别和执行结果；未唤醒导致的无识别不进入命令词分母，已唤醒后无识别进入命令词分母。
- 执行规则：基础命令词测试中同时统计集内串扰，A 命令被识别成 B 命令记为串扰；集内串扰是统计结果，不单独作为测试项。
- 关注结果：识别正确、识别为空/拒识、集内串扰、执行异常、连续失败。
- 统计公式：命令词识别率 = 识别正确次数 / 有效命令词样本数 * 100%；拒识率 = 识别为空次数 / 有效命令词样本数 * 100%；集内串扰率 = 集内串扰次数 / 有效命令词样本数 * 100%。
- 统计结果：命令词识别率、拒识率、集内串扰率、串扰矩阵、异常样本清单。

### 全命令覆盖
- 执行规则：核对测试数据是否覆盖产品支持的全部命令词、目标意图和关键参数类型。
- 执行规则：覆盖检查不替代识别率测试；缺失命令词或样本不足命令词应单独列出。
- 关注结果：是否存在漏测命令词、漏测意图、样本不足命令词或标注缺失。
- 统计公式：命令覆盖率 = 已覆盖命令词数 / 应覆盖命令词总数 * 100%。
- 统计结果：命令覆盖率、命令词覆盖清单、缺失项和样本不足项。

### 命令词反集误识别
- 执行规则：使用用户确认的命令词反集，唤醒设备后播放反集语料，记录是否被识别成正式命令词或触发动作。
- 执行规则：反集应与正式命令词分开统计，不与基础命令词识别率混算。
- 关注结果：反集是否被识别成正式命令词，是否触发高风险动作，问题是否集中在特定反集词。
- 统计公式：命令词反集误识别率 = 被识别成正式命令词的反集次数 / 有效命令词反集总次数 * 100%；反集触发动作率 = 触发动作次数 / 有效命令词反集总次数 * 100%。
- 统计结果：命令词反集误识别率、触发动作率、异常反集词清单。

### 命令词集外误识别
- 执行规则：使用不属于命令词集合的集外语料，唤醒设备后播放或喊测，记录是否被识别成正式命令词。
- 执行规则：集外语料与反集来源不同，应单独统计；不要与基础命令词识别率混算。
- 关注结果：集外语料是否被识别成命令词，误识别是否集中在某些意图或高风险指令。
- 统计公式：命令词集外误识别率 = 被识别成正式命令词的集外语料次数 / 有效集外语料总次数 * 100%。
- 统计结果：命令词集外误识别率、误触发命令清单、异常样本清单。

### 短词/长词/数字类指令
- 执行规则：从命令词中按短词、长词、数字类等维度分组测试，确保每组样本量满足分析需要。
- 执行规则：该项是命令词专项分析，结果应分类型呈现，不替代整体命令词识别率。
- 关注结果：特定类型命令是否集中失败、拒识或串扰。
- 统计公式：分类型识别率 = 该类型识别正确次数 / 该类型有效样本数 * 100%；分类型串扰率 = 该类型串扰次数 / 该类型有效样本数 * 100%。
- 统计结果：分类型识别率、分类型串扰率、典型 badcase。

### 噪声误识别
- 执行规则：唤醒设备后不播放命令词，只播放不含目标命令的噪声素材，记录是否被识别成命令词并触发动作。
- 执行规则：噪声内容、播放时长和声学场景需记录清楚；该项与命令词反集、集外语料分开统计。
- 关注结果：噪声是否被误识别成命令词，是否触发高风险动作。
- 统计公式：噪声误识别率 = 噪声被识别成命令词次数 / 有效噪声测试次数 * 100%；噪声误触发率 = 噪声触发动作次数 / 有效噪声测试次数 * 100%。
- 统计结果：噪声误识别率、噪声误触发率、误触发命令清单。

### 自激
- 执行规则：设备播放应答语、音乐、天气播报等自播内容，检查是否被再次识别成命令或触发动作。
- 执行规则：记录自播内容类型、自播音量、持续时长和触发时刻。
- 关注结果：是否发生回复送识别、多次执行或自播触发命令。
- 统计公式：自激触发率 = 自激触发次数 / 有效自播测试次数 * 100%。
- 统计结果：自激触发率、触发命令、触发时刻和自播内容清单。

### 识别打断
- 执行规则：设备播音过程中说另一条命令词，检查是否能打断自播并识别新的命令词。
- 执行规则：记录自播类型、自播音量、人声分贝、打断时机、目标命令词和实际识别结果。
- 关注结果：是否成功打断并识别第二条命令，是否存在打断失败或串扰。
- 统计公式：识别打断成功率 = 打断后正确识别次数 / 有效识别打断总次数 * 100%。
- 统计结果：识别打断成功率、打断失败样本、串扰样本。

### 离线 oneshot
- 执行规则：使用唤醒词和命令词连说或短间隔音频，记录唤醒和命令词识别两个环节。
- 执行规则：失败原因需拆分为唤醒失败、命令词未识别、命令词识别错误或执行异常。
- 关注结果：整体链路是否成功，失败主要发生在哪个环节。
- 统计公式：离线 oneshot 整体成功率 = 唤醒成功且命令词识别正确次数 / 有效 oneshot 总次数 * 100%。
- 统计结果：离线 oneshot 整体成功率、分环节失败统计、异常样本清单。

### 停顿/连读/语速
- 执行规则：使用停顿、连读、不同语速的命令词表达进行主观或专项测试。
- 执行规则：按停顿、连读、快慢语速等标签分组统计，不与基础命令词总体结果混算。
- 关注结果：自然表达变化是否导致拒识、串扰或执行异常。
- 统计公式：分语速/停顿识别率 = 该分组识别正确次数 / 该分组有效样本数 * 100%。
- 统计结果：分语速/停顿识别率、串扰率、典型 badcase。

### 角度/距离/姿态变化
- 执行规则：在不同角度、距离、姿态或走动状态下说命令词，记录对应场景参数和识别结果。
- 执行规则：角度、距离、姿态属于测试场景参数，应在测试场景中记录，不写入测试数据设计。
- 关注结果：真实交互条件下是否出现识别问题，问题是否集中在某些空间条件。
- 统计公式：分场景识别率 = 该场景识别正确次数 / 该场景有效样本数 * 100%。
- 统计结果：分距离/角度/姿态识别结果、问题记录、典型 badcase。

### 响应时间
- 执行规则：记录命令词人声结束到本地应答、提示音或设备动作开始的时间。
- 执行规则：只统计识别成功且执行链路有效的样本；失败样本单独记录原因。
- 关注结果：平均值、最大值、最小值、明显慢样本。
- 统计公式：平均响应时间 = 成功样本响应时间总和 / 成功样本数。
- 统计结果：命令词响应时间平均值、最大值、最小值、超阈值样本清单。
