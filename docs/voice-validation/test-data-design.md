## Polaris 使用原则

- 方案生成阶段先判断数据是否足够：正式数据、探索数据、合成数据、缺失数据要分开标注。
- 合成语料可用于 smoke/探索/压测，但不能替代正式声学集、噪声集、人群集或声压标定结论。
- 唤醒、命令词、自由说、在线识别、误唤醒的数据口径要分开统计，不要把前置失败混入功能分母。

# 测试数据设计模板

本文件只服务于 `voice-test-plan-designer` 生成测试方案。内容从语音效果测试知识库抽取并压缩，重点保留各测试大类的数据来源、样本数量、发音人/语速/口音、音频质量和测试集构造规则。

通用规则：词表、语料、反集、噪声素材等项目输入由生成脚本根据确认清单动态写入；本文件只写通用数据设计规则。距离、角度、分贝、SNR/信干比等声学参数属于测试场景，不写入测试数据设计模板。

## 唤醒

- 样本数量：摸底测试建议每唤醒词不少于 200 句；正式测试建议每唤醒词 400~500 句以上，最终以项目要求为准。
- 性别：男:女 = 1:1；如项目另有要求，以项目要求为准。
- 年龄：覆盖儿童 [0,10)、青年 [10,18)、成年 [18,60)、老年 [60,+)。
- 口音：覆盖标准普通话、带口音普通话。
- 语速：大客户项目可参考超快:快:慢:正常 = 2:3:1:4，最终以项目要求为准。
- 方言：待用户补充。
- 音频质量：不能缺字、多字、错字，不能有咳嗽、明显口气词、喷麦或发音含糊。
- 音频格式：建议 WAV，16bit，单声道，16k；平均幅值建议不低于 1000、不高于 10000，底噪平均幅值不高于 500。

## 命令词

- 样本数量：正式测试建议每句命令词至少 20 条语料音频；摸底测试可控制命令词总数不超过 400 句。
- 发音人：性别男、女尽量均衡；年龄覆盖儿童 [0,10)、青年 [10,18)、成年 [18,60)、老年 [60,+)。
- 口音：覆盖标准普通话和带口音普通话。
- 语速：正式测试按客户类型覆盖正常/快语速；大客户项目采用快:正常 = 1:1，其他客户使用正常语速；主观体验可使用正常/快/慢语速。
- 方言：如项目要求方言命令词，需单独补充方言语料和标注口径。
- 测试集构造：命令词正式识别率测试可使用“唤醒词 + 间隔 + 命令词”的方式构造音频，确保每条命令词在设备进入识别状态后播放；该构造是命令词测试的前置状态控制，不等同于重新评价唤醒率。
- 间隔要求：唤醒播放完成到命令词开始至少间隔 1 秒，且不能超过设备识别超时时间；命令词播放后到下一轮唤醒前至少间隔 3 秒，或等待上一轮应答完全播报结束后再开始下一轮。
- 前置唤醒片段：可使用一句语速正常、发音清晰的唤醒词音频循环使用；唤醒词音量可比命令词音量高至少 3dB，但最高幅值不应超过 20000，防止唤醒截幅。
- 离线 oneshot 构造：仅在产品支持或项目要求时单独构造；唤醒词后到命令词前的真实人声间隔固定覆盖 500ms、800ms、1000ms、1500ms，且需去掉唤醒词尾部静音和命令词前静音。
- 音频质量：命令词音频不能漏字、多字、错字、断错句；不应包含额外语气词，除非该说法本身作为独立词条有标注。
- 音频格式：建议 WAV，16bit，单声道，采样率按项目要求，常见 48k，最低 16k；每条音频前后静音约 1s。

## 自由说

- 样本数量：高频说法、非高频说法建议每个意图至少 3 句；纯 slot 说法建议每个意图至少抽取 1 个句式、每个句式至少 3 个纯 slot 组合说法。
- 发音人：性别男、女尽量均衡；年龄覆盖儿童 [0,10)、青年 [10,18)、成年 [18,60)、老年 [60,+)。
- 口音：覆盖标准普通话和带口音普通话。
- 语速：正式测试按客户类型覆盖正常/快语速；大客户项目采用快:正常 = 1:1，其他客户使用正常语速；主观体验可按正常/快/慢语速自由体验。
- 方言：如项目要求方言或口音自由说，需单独补充语料并单独统计。
- 测试集构造：自由说正式识别率测试可复用命令词测试的前置唤醒构造方式，使用“唤醒词 + 间隔 + 自由说”的方式组织音频，确保每条自由说在设备进入识别状态后播放；该构造不表示在自由说测试中重新评价唤醒效果。
- 间隔要求：唤醒播放完成到自由说开始至少间隔 1 秒，且不能超过设备识别超时时间；自由说播放后到下一轮唤醒前至少间隔 3 秒，或等待上一轮应答完全播报结束后再开始下一轮。
- 前置唤醒片段：可使用一句语速正常、发音清晰的唤醒词音频循环使用；唤醒词音量可比自由说音量高至少 3dB，但最高幅值不应超过 20000，防止唤醒截幅。
- 音频质量：自由说音频必须与标注说法一致，不能漏字、多字、错字或断错句；如果标准说法没有口气词，不应临时加入口气词。
- 音频格式：建议 WAV，16bit，单声道，采样率按项目要求；每条音频平均幅值建议不低于 1000、不高于 10000，底噪平均幅值不高于 500。

## 在线识别

- 样本数量：按领域/技能、设备控制类型、普通话/方言、半双工/全双工等维度补充有效样本数；摸底测试可使用 100 句快速验证链路。
- 标注信息：建议保留预期 ASR 文本、技能/意图、语种或方言标记；SID 作为复核字段按项目需要补充。
- 发音人：性别男、女尽量均衡；年龄覆盖儿童 [0,10)、青年 [10,18)、成年 [18,60)、老年 [60,+)。
- 口音：覆盖标准普通话和带口音普通话；带口音普通话不等同于方言。
- 语速：在线识别只使用正常语速，不按快/慢语速构造正式测试集或主观体验测试集。
- 方言/口音专项：如项目要求方言或口音在线识别，应单独构造、单独标注、单独统计，不能和普通话结果混算。
- 测试集构造：在线识别测试可使用“唤醒词 + 间隔 + 在线语料”的方式组织音频，也可人工先唤醒再说在线语料；未唤醒导致的无在线结果应先归入唤醒前置问题，设备已唤醒后仍无在线结果才进入在线识别为空/超时统计。
- 半双工构造：半双工要求每次在线识别前必须成功唤醒，测试顺序为唤醒、在线语料、唤醒、在线语料；唤醒失败时应重新唤醒，直到成功唤醒后再播放在线语料。
- 全双工构造：全双工测试第一次识别前必须成功唤醒；后续只要设备未退出识别状态即可连续播放在线语料；一旦日志显示退出识别，必须重新唤醒后再继续测试。
- 间隔要求：唤醒播放完成到在线语料开始至少间隔 1 秒，且不能超过设备识别超时时间；在线语料上一条播放完成到下一条开始至少间隔 1 秒，或等待上一轮应答完全播报结束后再开始下一轮。
- 在线 oneshot 构造：仅在产品支持或项目要求时单独构造；唤醒词后到在线语料前的真实人声间隔固定覆盖 500ms、800ms、1000ms、1500ms；如果半双工和全双工都测，必须分开统计。
- 音频质量：在线语料音频应与词条文本一致，不能漏字、多字、错字或断句错误。
- 数据标注：超长句、短句、尾弱音、带停顿等 VAD 专项语料应分组标注，避免混入普通句准。

## 误唤醒

- 噪声素材：应按安静、人声噪、非人声噪、多点噪等素材类型区分。
- 测试时长：各误唤醒场景的持续时长待用户补充。
- 素材合法性：噪声素材不应包含明确唤醒词；触发事件后的听音确认作为复核手段记录。
